## About This Project

This project analyzes a fictional small-business loan portfolio from a Florida community bank. The dataset contains information about business loans, including loan amounts, interest rates, credit scores, industries, regions, loan statuses, and profits.

The purpose of this project is to clean the dataset, explore the information using Python, and answer business questions about the loan portfolio.

## Project Structure

2. Make sure the dataset is inside the `data` folder.
3. Install the required packages using:

   `pip install -r requirements.txt`

4. Run the Python script using:
